# Order Management Policy

## Order Status

An order can have different statuses depending on its current processing stage.

Customers can use their order number to check the current order status.

## Order Information

Order information can include:

- Order number
- Order status
- Order date
- Expected delivery date
- Total amount
- Ordered products

## Cancelled Orders

If an order has been cancelled and the customer requires an explanation, the customer can contact support.

## Order Problems

Customers who have questions about an order can use the customer support system to request assistance.

## Support Tickets

A support ticket can be created when an issue requires additional assistance from customer support.
